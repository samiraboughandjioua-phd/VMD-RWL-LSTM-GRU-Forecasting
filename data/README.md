# Input data

Place the three hourly station files used in the study in this directory if you want to run the training scripts with their default settings.

Expected filenames:

- `Hourly_Water_Level_1984_2022_Tan_Chau_station.xlsx`
- `Hourly_Water_Level_1984_2022_Vam_Nao_station.xlsx`
- `Hourly_Water_Level_1984_2022_Can_Tho_station.xlsx`

The raw observations are intentionally not distributed with the GitHub package. Do not commit restricted or third-party data unless redistribution is permitted.
