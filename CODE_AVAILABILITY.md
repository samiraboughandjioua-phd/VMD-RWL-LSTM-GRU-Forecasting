# Code availability

This repository contains the custom computational code used for the study's LSTM and
GRU model training, statistical evaluation, residual diagnostics, high-water analysis,
and figure generation.

The repository is intended to support reproducibility of the published computational
workflow. Raw hydrological observations are not included because their redistribution
depends on data ownership and permission.

**Manuscript Code Availability statement (to be inserted once the Zenodo DOI is issued):**

> The custom code used for model training, statistical evaluation, and figure generation
> is available at https://github.com/samiraboughandjioua-phd>/VMD-RWL-LSTM-GRU-Forecasting (release v1.0.0),
> archived with a permanent DOI on Zenodo: https://doi.org/10.5281/zenodo.22879928. Raw
> hydrological observations are not included in the repository; requests for the
> underlying data should be directed to the corresponding author.
